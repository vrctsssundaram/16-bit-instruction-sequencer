# MicroSeq-16

Compact 16-bit deterministic control processing element with 16 registers, 8-bit program counter, branch/jump, arithmetic, peripheral input/output and illegal-opcode halt.

This is an independently defined microsequencer instruction set, not a RISC-V implementation. The external instruction memory must supply a combinational instruction for the current PC.

Run `make test` to execute the sample program and self-check its architectural results.
